Rijksoverheid fonts for the review interface
============================================

These are the Rijksoverheid house-style web fonts, copied from government.nl with the
Ministry's permission. They are licensed by the Dutch government, so they are kept out of
git: anyone setting up the project gets them from the team, not from GitHub.

  rijks-sans-regular.woff2   Rijks Sans, all weights (variable font): text, headings, buttons
  rijks-sans-italic.woff2    Rijks Sans italic
  ro-serif-regular.woff2     RO Serif: the original legal text
  ro-serif-bold.woff2        RO Serif bold
  ro-serif-italic.woff2      RO Serif italic
